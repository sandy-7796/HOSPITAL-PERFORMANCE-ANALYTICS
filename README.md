# HOSPITAL-PERFORMANCE-ANALYTICS (SQL to Power BI)

## Project Overview
This project focuses on analyzing hospital efficiency, patient waiting times, and bed utilization using SQL and Power BI.

## Tech Stack
* *Database:* MySQL / SQL Server
* *Visualization:* Power BI
* *Data Transformation:* Power Query & DAX
